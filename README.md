### 🛡️ About me

I design the platforms SOC teams work on. At **GMV's SOC/CERT** I build and run the infrastructure behind detection and incident response:

- **High-availability SIEM** with Wazuh, in critical-infrastructure environments.
- **Distributed data pipelines** on Apache Kafka, deployed across multiple physical sites so they keep running even if one goes down.
- **Splunk SOAR playbooks** to automate response.
- **AI agents** (LangGraph) that automate alert enrichment and triage, deployed on Kubernetes.

I started as an **L1 SOC analyst**, so everything I build is designed around the analyst's day-to-day: less noise, faster triage.

- 🎓 Studying a **MSc in Cybersecurity and Privacy (UOC)** · BSc in Computer Engineering (University of Valladolid)
- ☸️ Preparing for the **CKA** (Certified Kubernetes Administrator)
- 🎤 Speaker at **Navaja Negra**
- ⚡ Driven by challenges where security, reliability and automation meet
